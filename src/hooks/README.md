# hooks/

Hooks compartidos. Ejemplos previstos:

- `useAudio` — reproducir/repetir el audio de una instrucción o feedback.
- `useReducedMotion` — detectar la preferencia de movimiento reducido.

Estado actual:

- `useAudio.js` ya reproduce instrucciones y feedback.
- `useReducedMotion.js` sincroniza la preferencia del sistema con el store.
